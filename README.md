# Kalidas R. — Portfolio (React + TypeScript + Vite)

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist
```

- `src/Background.tsx` — fullscreen WebGL background (waves, orbs, dot grid, cursor light)
- `src/PhotoGL.tsx` — your photo drawn through a WebGL shader (ripple, RGB split, idle wave)
- `src/sections.tsx` — Hero, Work (with Load more), Services, Process, About, Contact
- `src/assets/me.png` — your cutout photo
- Deploy `dist/` to Vercel, Netlify or GitHub Pages.
